Zotero Local Clean uses its own Marketplace ID, `logseq-zotero-local-clean`. The original Zotero Local plugin keeps its own listing and settings. This edition requires a Logseq 2.x DB graph and has been tested with Logseq Desktop 2.0.2 and the local Zotero API.

- Import an item with **/Zotero Clean: Insert full item**. The clean profile preserves subject tags, writes abstracts and notes as blocks, and hides import identifiers.
- Paper lookup and annotation sync recognize identifiers from the earlier clean edition. Switching from `3.5.6-clean.2` does not require reimporting your library. Set any custom plugin preferences again under the new ID.
- The release ZIP contains the built plugin. The original upstream author is benjypng; this edition is maintained by hzphzp.
