# v3.5.6-clean.2 — Logseq 2.0.2 DB 精简导入版

本版本将 Zotero 本机导入调整为适合 Logseq 新数据库图谱的精简工作流，修复迁移属性重复、页面模板噪声、引用写入和错误提示问题。

## 支持版本

- **仅面向 Logseq 2.0.2 起的 2.x DB 图谱。** 实际验证：Desktop 2.0.2 / revision 533ac43。
- **不支持 0.10.x，不支持 Markdown／Org 文件图谱。** 旧版模板插入入口不再注册。
- 此 Release 是基于上游 v3.5.6 的独立维护分支；后续 Logseq 版本需要重新验证兼容性。

## 主要变化

- 保留完整学科标签；逗号不拆分标签，复用已有 Tag。
- 优先复用旧图谱的作者、日期、条目类型、DOI 等属性及其类型，避免再生成一套重复字段。
- 正文统一为“摘要／笔记／附件与批注”普通标题；导入追踪信息隐藏，不追加属性文本抽屉。
- 按条目 ID 识别已有论文，兼容旧 `links` 属性和元数据存放于子块的情况；改名后不重复建页。
- 导入全部独立笔记，完整处理列表分页，保留 Zotero 本地 PDF 链接。
- 正文改为逐块写入，导入期间不提前跳转；最后以页面 UUID 插入引用，并保留输入块原文。
- 阻止重复点击；错误提示包含具体步骤和原因，并在本机保存最近一次错误，避免只显示 `[object Object]`。

## 安装

下载 `logseq-zoterolocal-plugin.zip`，退出 Logseq 后将其中的同名目录放入 `~/.logseq/plugins/`，然后重新打开 Logseq。保持 Zotero 运行，在空白块使用 `/Zotero: Insert full item`。

本分支沿用上游插件 ID 和属性命名空间，不能与上游版本同时启用。已有设置和图谱数据保留；后续请从本仓库更新。

## 验证与范围

- TypeScript 检查、生产构建通过。
- 真实 Logseq 2.0.2 worker 的独立图谱集成测试通过，包括属性类型复用、分类名、正文保留、重复导入与错误恢复提示。
- 真实论文、PDF 链接及 Zotero 笔记导入验证通过；桌面端重载后无报错、页面正常。
- 发布包只包含插件程序和文档，不包含个人笔记、账号配置、密钥或图谱备份。
- 本版本不会批量整理旧笔记，也不搬运或修复缺失的 PDF；旧学科标签自带的字段模板需要单独整理。
